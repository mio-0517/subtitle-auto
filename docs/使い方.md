# 英語動画 → 日本語字幕 自動化ツール

英語のトレード解説動画（TJR の bootcamp 等）を inbox に放り込むだけで、
日本語字幕付きの動画が output に出てくる。

処理の流れ：
`動画 → 音声抽出(ffmpeg) → 英語書き起こし(Whisper) → 用語辞書つきLLM翻訳 → SRT → 動画に字幕トラック追加`

YouTube の自動翻訳と違うのは **用語辞書を効かせている**点。
FVG / order block / liquidity sweep / BOS / CHoCH みたいな SMC 用語が毎回同じ訳になる。

## 初回セットアップ（1回だけ）

このフォルダの **`セットアップ.command` をダブルクリック**するだけ。（実行済み）
（ターミナルが開いて自動で進みます。途中で Claude Code CLI を入れるか聞かれます）

ターミナル派なら：

```bash
cd ~/開発プロジェクト/subtitle-auto
bash setup.sh
```

やっていること：
1. `.venv` を作る
2. Apple Silicon なので `mlx-whisper` を入れる（M系チップ最適化。速い）
3. `ffmpeg` を確認（無ければ pip 版を入れるので brew 不要）
4. 翻訳エンジンを確認
5. フォルダ監視を launchd に常駐登録（Mac 再起動後も自動で動く）

### 翻訳エンジン（どちらか）

**A. Claude Code CLI を使う（追加課金なし・おすすめ）**

```bash
npm i -g @anthropic-ai/claude-code
claude   # 一度起動してログイン
```

**B. API キーを使う（安定・従量課金）**

```bash
echo 'ANTHROPIC_API_KEY=sk-ant-xxxxx' > ~/開発プロジェクト/subtitle-auto/.env
```

18分の動画で数十円程度。

## 使い方

**`画面を開く.command` をダブルクリック** → ブラウザに字幕メーカーが出る。
そこに動画をドラッグして放り込むだけ。

### 翻訳の流れ

いまは **翻訳を Claude(チャット) が担当する設定** になっている（`config.json` の
`translate_engine: "manual"`）。ログインもAPIキーも要らない。

1. 動画を入れる → 英語の聞き取りまで自動で進み、**「翻訳待ち」**で止まる
2. Cowork のチャットで **「訳して」** と言う
3. Claude が日本語字幕を入れて動画まで仕上げる → 「完了」になる

Claude 側の作業はこの3コマンド（人が打つ必要はない）:

```bash
python3 manual.py list          # 翻訳待ち一覧
python3 manual.py show <id>     # 英語の行を出す
python3 manual.py apply <id> 訳.json   # 訳を入れて仕上げる
```

将来ログインやAPIキーに戻す場合は `config.json` の `translate_engine` を
`auto` に戻すだけ。

画面でできること：
- 動画をドラッグ＆ドロップして投入
- 今どこまで進んだか（聞き取り中／翻訳中 120/260行 …）をリアルタイム表示
- 完了したら「▶ 見る」でその場で字幕付き再生（VLC不要）
- 「字幕を保存」で .srt だけ取り出す

この画面は **自分のMacの中だけ**で動いている（`localhost:8765`）。ネットには出ないし、
他人からは見られない。

Finder の `inbox` フォルダに直接入れてもOK（画面と同じように処理される）。

出来上がりの置き場所：
```
output/         ← 日本語字幕付き動画と .srt
inbox/_処理済み/ ← 成功した元ファイル
inbox/_失敗/     ← エラーになった元ファイル
```

うまく動かないときは **`再起動.command`** をダブルクリック。

手動で1本だけ処理したいとき：

```bash
cd ~/開発プロジェクト/subtitle-auto
.venv/bin/python process.py /path/to/video.mp4
```

## 字幕の見方

デフォルトは **ソフトサブ**（字幕トラックを埋め込み・再エンコードなしで速い）。

- **VLC**：字幕メニューから日本語／English を切り替えられる
- **QuickTime**：日本語トラックが表示されないことがある → VLC 推奨
- 動画に直接焼き付けたい（SNSに上げる等）なら `config.json` の
  `"subtitle_mode"` を `"hard"` か `"both"` に変える
  - ただし焼き付けには libass 入りの ffmpeg が必要。Homebrew が入っているので
    `brew install ffmpeg` を一度実行しておくと確実（入れれば自動でそちらを使う）

---

## 設定 `config.json`

| 項目 | 説明 |
|---|---|
| `mlx_model` | Whisper モデル。精度優先なら `mlx-community/whisper-large-v3-mlx` |
| `chunk_size` | 一度にLLMへ渡す字幕行数。25前後が精度とコストのバランス良い |
| `context_lines` | 前後の文脈として渡す行数。訳のつながりが良くなる |
| `subtitle_mode` | `soft`(埋め込み) / `hard`(焼き付け) / `both` |
| `max_chars_per_line` | 1行あたりの日本語文字数。20前後が読みやすい |
| `anthropic_model` | API 利用時のモデル |

## 用語辞書 `glossary.json`

ここに `"英語(小文字)": "日本語"` を足すだけで訳がブレなくなる。
**訳が気に入らない用語が出たら、まずここに足すのが一番効く。**

## トラブル時

```bash
# 監視プロセスが動いてるか
launchctl list | grep subtitle-auto

# 再起動
launchctl unload ~/Library/LaunchAgents/com.mio.subtitle-auto.plist
launchctl load   ~/Library/LaunchAgents/com.mio.subtitle-auto.plist

# エラーログ
tail -50 ~/開発プロジェクト/subtitle-auto/logs/watcher.err.log
```

同じ動画を再処理したいときは `work/` の中の該当キャッシュ（`*.en.json`）を消すと
書き起こしからやり直す。消さなければ翻訳だけやり直すので速い。
